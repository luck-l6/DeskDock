# DeskDock

Windows 桌面收纳器。把桌面和开始菜单里的应用收进一个面板，桌面上只留一个
可拖动的悬浮胶囊入口 —— 桌面干净了，文件一个都没动。

唤出面板后：

- **搜索**：`wx` 能搜到微信，`vsc` 能搜到 Visual Studio Code（拼音首字母 + 英文缩写）
- **分类**：应用 / 文件 / 文件夹 / 常用，按快捷方式指向的目标自动归类
- **排序**：按使用频率、按名称，或者手动拖到你想要的位置
- **装了新软件不用手动刷新**：源目录在监听，安装完自动出现

## 先说清楚它不做什么

这是整个设计的前提，也是它和"桌面整理工具"最大的区别：

1. **不移动、不复制、不删除你的任何文件**。桌面图标只是"不再由 Explorer 绘制"，
   文件完整留在原目录。任何把快捷方式搬进某个文件夹的方案都不采纳。
2. **一切可逆**。程序崩了、退出了，你随时能恢复系统桌面图标（托盘菜单里有开关）。
3. **只读扫描 + 图标缓存**，不做写操作，不碰用户数据。

## 安装

### 直接用打包好的 exe

从 Releases 下载 `DeskDock.exe`，双击即用，不需要装 Python。

### 自己打包

```bat
python -m PyInstaller tools/build.spec --noconfirm
```

`tools/build.spec` 顶部有个 `MODE`：

| MODE | 产物 | 体积 | 冷启动 |
|---|---|---|---|
| `onedir`（默认） | `dist\DeskDock\DeskDock.exe` | 141 MB | **1.3 s** |
| `onefile` | `dist\DeskDock.exe` | 55 MB | 7.8 s |

**日常自用选 `onedir`**。单文件版每次启动都要把 55MB 重新解压到 `%TEMP%`，
实测 7.2 秒全花在这上面（程序自身只要 0.56 秒）；它只适合拷给别人时用。

### 从源码跑

Python 3.12 + PyQt5 5.15：

```bat
pythonw main.py          :: 正常运行
python main.py --selftest :: 自检：打印 QML 根对象数和加载警告，不隐藏桌面图标
```

## 用法

| 操作 | 说明 |
|---|---|
| `Alt+Q` | 唤出 / 收起面板（热键可在设置里改） |
| 点胶囊 | 同上 |
| Esc / 点面板外 | 收起面板 |
| 输入 | 搜索，支持拼音首字母；有查询时不做分类过滤，全库搜 |
| 右键条目 | 隐藏 / 置顶 / 在资源管理器中显示 |
| 长按拖动 | 手动排序（第一次拖动会自动切到手动模式） |
| 托盘图标 | 显示面板、重新扫描、切换视图、显示桌面图标、设置、退出 |

设置里能切：居中卡片 / 全屏 Launchpad 两种视图，排序方式，要不要收纳
公共开始菜单、要不要藏控制台程序（MySQL 命令行这类）。

## 桌面图标一定会还回来

隐藏桌面图标是写进注册表的（`HideIcons=1`）。进程一旦崩溃或被强杀，没有任何
代码会去把它改回来 —— 桌面图标就这么消失了，而托盘也跟着进程一起没了。
所以做了三层兜底：

1. **崩溃钩子**：`SetUnhandledExceptionFilter`，真崩溃时当场恢复
2. **RunOnce 兜底**：下次登录由 Windows 替你恢复（纯 cmd 命令，不依赖 Python）
3. **下次启动自检**：发现上次没正常退出，先把图标状态同步一次

外加托盘菜单里的手动开关，任何时候都能自己开回来。

需要说明的是：第 2 层只在**下次登录**时执行。如果程序被强杀而你既不重启它
也不注销，桌面图标会一直是隐藏的 —— 这时右键桌面 → 查看 → 显示桌面图标即可。

## 实测数据

2026-10-23 用 `tools/assess.py` 实测（真实 exe，非自检模式）：

| 指标 | 值 |
|---|---|
| 冷启动（onedir / onefile） | 1.3 s / 7.8 s |
| 唤出延迟 | 60–83 ms，中位 65 ms |
| 常驻内存 | 319 MB（物理） |
| 扫描 | 155 条去重后 145 条，图标命中 145/145 |
| QML 加载 | 根对象 3/3，0 警告 |
| 目录监听 | 59 个目录 |

复现：

```bat
python tools/assess.py                       :: 测单文件版
python tools/assess.py dist\DeskDock\DeskDock.exe  :: 测目录版
python tools/crash_recovery_test.py          :: 测强杀后的图标恢复链路
```

## 目录结构

```
deskdock/
  app.py        Controller：属性/槽、面板显隐、目录监听、退出清理
  scanner.py    扫描桌面与开始菜单，解析 .lnk、判定分类
  model.py      QSortFilterProxyModel：分类、搜索、三种排序、拖拽落位
  pinyin.py     拼音/缩写匹配
  pinyin_data.py 离线拼音表（由 tools/gen_pinyin.py 生成）
  icons.py      图标提取与磁盘缓存（含缓存回收）
  desktop.py    桌面图标显隐、三层恢复兜底
  backdrop.py   抓屏 + 降采样，给毛玻璃当底图
  hotkey.py     全局热键（独立线程）
  qml/          Panel / Capsule / Settings / 各 delegate
tools/          打包配置与一堆验证脚本
```

## 已知问题

- 常驻内存 319 MB 对托盘程序偏高
- 图标缓存有回收逻辑，但换过提取算法后旧版本文件要等下次扫描才清掉
- 唤出延迟的 95% 是抓屏。复用上一帧能压到 20ms，但底图会和真实桌面
  对不上，而"桌面前台是什么就读什么"正是这个工具要的，所以没做
